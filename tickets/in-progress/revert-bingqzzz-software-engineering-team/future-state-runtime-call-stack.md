# Future-State Runtime Call Stack: Normal Software Engineering Team After Revert

1. Team loader reads `agent-teams/software-engineering-team/team-config.json`.
2. `solution_designer` remains the coordinator and normal entry specialist.
3. The normal team uses its existing engineering specialists and delivery handoff rules.
4. No Product Manager agent package is loaded from the normal team directory.
5. Product iteration remains outside this revert scope in its separate team directory.

Boundary: this model describes normal one-off Software Engineering Team behavior after the requested cleanup; it does not modify or remove the separate Product Iteration Team.
